# Simple Linktree

A simple personal link page built with Node.js.

This project was made for learning and practicing
basic web development using Node.js, HTML, CSS, and JavaScript.

## Features
- Custom profile
- Social media links
- Add or remove buttons using JSON
- Responsive design

## Run Locally

1. Install Node.js
2. Clone this repository
3. Run `node server.js`
4. Open http://localhost:3000
